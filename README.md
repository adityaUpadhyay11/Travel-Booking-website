🌍 WanderNest – Smart Travel Planner
WanderNest is a responsive web application designed to simplify destination exploration and trip planning. Whether you're looking for your next adventure or organizing a detailed itinerary, WanderNest provides a seamless, interactive experience for modern travelers.

🚀 Features
Destination Discovery: Explore various travel spots with dynamic content rendering.

Smart Itineraries: Personalized trip suggestions based on user input.

Secure Authentication: Full sign-up and login functionality powered by a MySQL backend.

Responsive Design: Fully optimized for desktop, tablet, and mobile viewing.

Form Validation: Real-time client-side validation for a smooth user experience.
